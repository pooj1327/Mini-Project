# GapWise AI

An Intelligent Skill Gap Detection Platform

## Features

- Login
- Register
- Resume Parsing
- Skill Gap Analysis
- AI Roadmap
- Assessments
- Progress Tracking
- Email Notifications
- Dashboard Analytics

---

## Installation

Create Virtual Environment

```bash
python -m venv venv
```

Activate

Windows

```bash
venv\Scripts\activate
```

Install Packages

```bash
pip install -r requirements.txt
```

Run

```bash
streamlit run app.py
```
